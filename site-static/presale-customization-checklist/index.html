預售屋・室內變更

預售屋客變怎麼做？期限、圖說、追加減帳與驗收清單

買房資訊王｜發布與資料查核：2026-11-24

「客變」是買方與建商約定，在施工條件允許時變更室內隔間、裝修或建材設備；不是每個建案依法都必須提供，也不是口頭提出就一定生效。先讀實際契約的範圍、期限、次數、費用與付款規則，再用雙方簽認的工程變更單、圖說與追加減帳作為施工和交屋驗收依據。〔1〕

內政部提供的預售屋買賣契約書「範本」包含建築設計變更參考條款；建案實際是否提供、何時截止及如何計價，仍以雙方契約與工程進度為準。不要把範本條文直接當成每份契約必然具備的權利。

簽約前，先把「有沒有客變」問成六個書面問題

  1. 本戶是否提供客變？申請截止日或工程進度門檻是什麼？
  2. 可以申請幾次？逾期、再次變更或取消要如何處理？
  3. 可變更的隔間、插座、給排水、建材和設備範圍各是什麼？
  4. 建商拒絕結構、外觀、消防、公共設施或已發包項目的依據是什麼？
  5. 設計、管理、材料與施工如何計價？減帳是何時退還或抵扣？
  6. 誰負責提出詳圖、申請必要核准，完工後交付哪些圖說？

把答覆寫進契約附件或雙方簽認文件，不要只保存銷售人員的口頭說法。簽約前可搭配預售屋契約審閱清單，確認客變規則和付款、建材設備表、格局圖使用的是同一版本。

哪些項目通常可能變更？哪些不應只憑買方要求就改？

實際可否辦理仍看契約、法令、工程進度及其他住戶權益
類型常見處理先核對
室內隔間可能調整非結構隔間、門片或空間配置。牆體性質、消防、逃生、通風採光與管線。
插座與弱電可能增減位置或迴路，但受配電、管線及施工進度限制。迴路容量、專用迴路、配電盤及圖例。
給排水常受樓板、管道間、坡度及影響下層住戶限制。防水、排水、存水彎、檢修與樓下影響。
建材設備可能退選、換色或換型號，也可能因已採購而不受理。品牌型號、價差、保固、替代品與交付方式。
結構與公共系統主要結構、外觀、管道間、消防及公共設施通常不屬買方可任意變更範圍。核准圖說、建築安全及其他共有人權益。

內政部契約書範本將買方變更範圍放在室內隔間及裝修，並明列主要結構、立面外觀、管道間、消防設施及公共設施等不得要求變更；同時要求不得違反建管法令，需主管機關核准時由賣方依規定申請。這是簽約比對的重要參考，不是鼓勵用客變規避核准圖說。〔1〕

預售屋客變流程怎麼走？

  1. 取得原始基準：收齊契約、原平面圖、建材設備表、水電配置與建商客變規則。
  2. 在期限前提案：用有尺寸、符號及說明的圖面提出，確認哪些項目尚未施工或採購。
  3. 逐項協調：把同意、拒絕、替代方案、責任與是否需核准記錄清楚。
  4. 簽工程變更單：雙方確認圖號、版本、項目、數量、單價、工期及簽認日期。
  5. 簽追加減帳：核對追加、減少、管理費、稅額、付款期限與結清時間。
  6. 保存付款證明：付款對象與金額須能對回已簽認的變更文件。
  7. 完工驗收：以原契約加最終客變圖說逐項核對，不只憑現場口頭解釋。

追加減帳不能只看「總差額」

內政部契約書範本的參考流程，是雙方簽認工程變更單後，由賣方提出追加減帳，再由買方簽認；追加款與減帳的付款或結清時間也應明確。實際建案條款可能不同，因此要逐項核對，不要只簽一個總額。〔1〕

  • 刪除原建材的減帳，是按契約單價、採購價還是另訂標準？
  • 新增項目是否另收設計費、管理費、施工費與稅額？
  • 同一工程有沒有把數量、單價與工資重複計入？
  • 追加款何時到期；減帳何時退款、抵扣或交屋結清？
  • 變更未完成、未如期付款或雙方未簽認時，是回復原設計還是另行處理？
實用表格欄位：原項目／變更後項目／數量／單價／追加／減少／管理費／稅額／圖號／付款日／雙方簽章。空白欄劃線，修改處重新簽認並標日期。

客變圖說要留下哪些版本？

至少保存原始圖、提案圖、建商回覆圖、雙方最終簽認圖及追加減帳。圖面要有戶別、圖號、比例或尺寸、版本日期與簽章；水電、給排水、天花和設備若分圖，應使用同一版次索引。

臺中市政府消保官提醒，預售屋驗收應索取驗收單、房屋平面圖、建材設備表及水電器具配置圖；若有約定客變，也應取得客變圖說，才能核對完工品質是否符合契約。〔2〕

交屋驗收時，怎麼把客變逐項驗回來？

  1. 用最終簽認圖核對隔間尺寸、門向、插座、開關、燈具出線與給排水位置。
  2. 用建材設備表及變更單核對品牌、型號、顏色、數量與退選項目。
  3. 以照片、尺規與編號記錄差異，逐項寫入驗收單並保留雙方簽認版本。
  4. 確認缺失修繕期限、複驗日期及未完成項目的款項處理，不把「交屋後再說」當成完整紀錄。
  5. 保存最終竣工或配置資料，供入住後維修、鑽孔與裝修判讀。

客變驗收仍屬整體交屋驗收的一部分。房地總價 5% 交屋保留款、瑕疵紀錄與複驗流程，請另看預售屋驗屋與交屋保留款指南。

簽客變文件前的最後清單

  • 戶別、圖號、版次與日期一致。
  • 每個新增、取消與保留項目都有文字及圖面。
  • 結構、消防、外觀、管道間與公共設施沒有被口頭承諾規避。
  • 追加減帳有數量、單價、管理費、稅額與結清日。
  • 付款條件、逾期處理與未簽認時的施工基準明確。
  • 建材設備的品牌、型號、色號與替代規則可驗收。
  • 雙方逐頁簽認並各自留存完整副本；後續修改另編新版，不覆蓋舊檔。
