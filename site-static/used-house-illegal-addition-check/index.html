先說結論：沒有任何一張文件可以單獨證明中古屋「完全沒有違建」。先以建物謄本找出登記面積與附屬建物，再取得使用執照及核准竣工圖，與現場的頂樓、陽台、夾層、一樓空間逐項比對；同時看建物現況確認書與所在地政府的違建案件紀錄。地方系統查無案件，只代表目前查詢範圍內沒有紀錄，不等於現況已被認定合法。
本文整理台灣中古屋的一般查核流程。違建認定、既存違建日期、查報與拆除順序由標的所在地主管建築機關依個案與地方規定處理；不要只憑屋齡、鄰居都有或「目前沒被檢舉」判斷安全。

什麼情況可能是違建？先分清「未登記」與「未經許可」

依違章建築處理辦法，依法應申請主管建築機關審查許可並取得執照，卻擅自建築的建築物，屬違章建築。建築法也規定，建築物原則上不得未經許可擅自建造、使用或拆除；違反規定可能被處罰、勒令停工、補辦手續，必要時強制拆除。〔1〕〔2〕

「權狀沒有」是一個警訊，但不宜直接當成主管機關已認定違建；相反地，地方違建系統查不到案件，也不會讓未經許可的增建自動合法。最可靠的做法是比對核准圖說與現況，遇到差異時向標的所在地建管機關確認。

簽約前五步查核：從面積差異追到主管機關

  1. 先畫現況：逐層記錄房間、陽台、露臺、夾層、頂樓與一樓增建；拍攝位置與外觀，不要只抄廣告坪數。
  2. 核對登記：用最新建物謄本及測量成果圖比對層次、主建物、附屬建物與面積。實際使用面積明顯大於登記面積時，要求賣方逐項解釋差額。
  3. 調閱建管資料：取得使用執照號碼與核准竣工圖。內政部國土署提醒，購買成屋或二手屋可要求售屋者出示使用執照，再向地方主管建築機關查詢；合法夾層可辦理產權登記，非法夾層則不能。〔4〕
  4. 查地方紀錄：使用標的所在地政府的違建查詢或向建管機關申請資料；記下查詢日期、地址、文號、涵蓋期間與結果。
  5. 要求書面結論：把所有差異列入現況確認書、不動產說明書及契約附件。無法確認時，不要用「依現況交屋」帶過，可先暫停出價或把補件、確認及未完成的效果寫成條件。

若不會比對圖面，可請建築師或相關專業人員協助現勘；地政士擅長登記與交易流程，但違建、結構或建築法規疑義仍應找對應的建築專業與主管機關。

地方系統查無違建紀錄，就代表合法嗎？

不代表。各縣市公開系統的涵蓋範圍、年份、查詢條件與資料狀態不同。例如新北市官方查詢頁明示，系統僅提供特定期間以後的一般違建排拆紀錄，並特別提醒結果不代表目前現況的違建情形。〔5〕

因此，查詢結果要這樣解讀：

  • 查到案件：記下認定或通知文號、處理狀態與標的範圍，向主管機關確認；不要只聽賣方說是「緩拆」。
  • 查無案件：繼續比對使用執照竣工圖及現場；查無紀錄可能只是未被查報、資料未公開或不在系統涵蓋範圍。
  • 地址查不到：改用門牌、地號、建號或執照號碼詢問所在地建管機關，不要用搜尋失敗當成合法證明。

地方政府對既存違建的劃分日期與處理順序可能不同，但「既存」或「緩拆」不等同合法，也不等同未來不會處理。違章建築的查報、認定與拆除由地方主管建築機關執行。〔2〕

查到增建後，怎麼寫進出價與買賣契約？

不要只寫「現況交屋」或「買方已知」。至少把下列事項做成附件，由雙方逐項確認：

  1. 位置與範圍：哪一樓、哪個空間、約多少平方公尺，附照片與圖面標示。
  2. 文件狀態：有無登記、是否出現在核准竣工圖、是否已有查報、認定、拆除或補辦通知。
  3. 價格分界：契約總價中不要把未登記增建誤寫成有權狀面積；議價時分開看合法登記面積與額外使用現況。
  4. 交屋前處理：由誰負責補件、恢復原狀、拆除或取得主管機關說明，完成期限與費用由誰負擔。
  5. 條件未成就：若主管機關認定、銀行鑑價或貸款結果不符約定，是否得解除、價款如何返還及費用如何結算。
  6. 後續責任：交屋後收到查報或拆除通知時，雙方責任及既有文件、通知是否已完整移交。

內政部官方購屋提醒也建議，先向建商或房仲取得不動產說明書與平面圖，比對建物謄本，並查地方違建系統；未列入權狀的額外空間可能面臨拆除風險，不宜因多出的使用坪數忽略風險。〔6〕

可搭配中古屋斡旋金、要約書與出價條件，把補件期限、貸款條件與未完成時的退還方式寫進出價文件，而不是等正式簽約後才處理。

交屋前，還要再確認哪些事情？

  • 重新取得最新違建案件或主管機關回覆，確認簽約後是否新增通知。
  • 逐項比對契約附件照片與現況，確認賣方約定拆除、恢復或補件是否完成。
  • 向貸款銀行提交同一套登記及增建資料，確認核貸、鑑價與撥款條件，不要把口頭預估當成承諾。
  • 點交全部使用執照、竣工圖、違建查詢、主管機關函文、規約及修繕文件。
  • 驗屋時另查漏水、結構接合、用電與排水；違建查核通過不代表增建施工品質安全。

產權、抵押權、屋齡與使用執照的完整查詢順序，請接著看中古屋產權與屋齡查核清單；實際屋況可用中古屋看屋檢查表及建物現況確認書指南交叉核對。

常見問題

頂樓加蓋是舊違建，就一定不會拆嗎？

不是。各地既存違建日期、分類、優先處理及排拆進度不同；「緩拆」也不是合法證明或永久不拆保證。應以所在地主管建築機關對個案的最新書面資料為準。

權狀沒有陽台外推面積，就一定是違建嗎？

權狀與現況不一致是需要追查的警訊，但是否違反建築法規仍要看原核准圖說、施工內容、建築管理時點及地方主管機關認定。不要只靠面積差額自行下結論。

房仲說「現況交屋」，賣方就不用揭露嗎？

現行成屋契約的建物現況確認書明列未登記改建、增建、加建及違建範圍，且違建應說明拆除風險。「現況交屋」不應取代具體位置、面積、文件與處理方式的揭露。〔3〕
