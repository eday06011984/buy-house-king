房地合一稅的成本、費用，影響哪個算式？

財政部列示的基本計算順序，是先用成交價減除可證明的成本及費用，再處理符合規定的房地交易損失與土地漲價總數額：

房屋土地交易所得＝出售成交價額－可減除成本－可減除費用
課稅所得＝交易所得－可扣除的房地交易損失－土地漲價總數額

所以「保存憑證」不是把所有花費加總，而是把每筆支出放回正確類別。買入價及達可供使用狀態前的必要費用，與出售時的必要移轉費用，認定條件並不相同。〔1〕

裝潢、修繕費都有發票，就都能列成本嗎？

不是只看有沒有發票。財政部說明的是「增加房屋價值或效能，而且不是2年內所能耗竭」的增置、改良或修繕費。一般日常維護、短期耗材或與標的不明的家電家具，不宜直接視為可減除成本。

  • 工程契約要寫施工地址、範圍、材料、金額與工期。
  • 發票或收據的買受人、品名及金額要能與工程對應。
  • 保留估價單、前後照片、驗收紀錄及銀行付款資料。
  • 同一張發票若混有家具、家電與固定工程，要求廠商分項。
  • 付款人與房屋所有權人不同時，先確認如何證明負擔關係。

能否增加價值或效能、是否屬短期耗竭，仍可能有個案判斷；工程開始前可攜帶報價向國稅局詢問，不要等到出售申報時才整理。

出售房屋時，哪些必要費用可能減除？

財政部列舉房屋土地移轉時支付的仲介費、廣告費、清潔費及搬運費等必要費用；申報時要檢附「個人房屋土地交易成本費用明細表」及相關證明。〔1〕

  • 賣方仲介服務費與實際付款證明。
  • 為出售標的支付的廣告或平台費。
  • 因交易移轉所必要的清潔、搬運或其他支出。
  • 其他直接與本次出售相關、必要且能舉證的移轉費用。

同樣是「清潔費」，日常居住期間的清潔費與出售移轉所必要的清潔費，稅務定位可能不同。保存資料時應註明日期、目的及與本次交易的關係。

哪些常見支出不能當作房地合一稅費用減除？

財政部明列，取得房地後使用期間的下列支出屬持有或使用的相對代價，不能直接列為出售交易費用：〔3〕

  • 房屋稅、地價稅。
  • 社區管理費及使用期間清潔費。
  • 所有權移轉登記完成後、持有期間的房貸利息。
  • 一般依土地稅法繳納的土地增值稅；特殊可列部分另有計算規定。
常見誤區：自住優惠並不會把持有稅、管理費或全部房貸利息變成可扣成本；「有付款」「與房子有關」仍不足以證明符合房地合一稅的減除規定。

買房後，憑證怎麼保存才看得懂？

  1. 原始取得：保存買賣契約、付款期程、匯款與履約保證紀錄。
  2. 稅費規費：分開保存契稅、印花稅、登記規費與各項繳款書。
  3. 服務報酬：保存仲介、代書、公證的契約、發票或收據及付款紀錄。
  4. 裝修改良：每個工程建立資料夾，收進報價、合約、發票、付款與照片。
  5. 房貸利息：保留銀行明細並標記所有權移轉登記日，分清登記前後。
  6. 出售費用：另建出售資料夾，不與多年持有費用混在一起。

沒有費用憑證，就一定可以扣成交價3%嗎？

不能把「3%、30萬元上限」誤解為全部成本的固定扣除額。財政部說明，若未能提示費用證明，或提示的費用證明金額未達成交價額3%，稽徵機關得按成交價額3%計算可減除的費用總額，並以30萬元為限。這段規則處理的是費用認定，不能取代買入價金、符合條件的改良成本等原始證明。〔3〕

例如成交價2,000萬元，3%是60萬元，但規則仍受30萬元上限限制；這只是說明上限，不代表個案必然核定30萬元，也不是放棄保存實際費用憑證比較有利。

未來出售時，申報前核對什麼？

  1. 確認交易是否適用房地合一稅及正確取得日。
  2. 用買入與賣出契約核對實際成交價額。
  3. 逐項區分取得成本、改良成本、出售移轉費用與不得減除支出。
  4. 填寫成本費用明細表，讓每個金額都能連到證明文件。
  5. 一般房地自完成所有權移轉登記日次日起30日內申報，不等隔年5月。
  6. 若主張自住優惠、重購退稅或交易損失，再附各該資格與計算資料。

財政部申報說明要求檢附買入及賣出的買賣契約、成本及必要費用證明等文件。〔4〕 自住滿6年與400萬元免稅條件，可另看房地合一稅自住優惠指南。
