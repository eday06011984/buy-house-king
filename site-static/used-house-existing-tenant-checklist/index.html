看到屋內有租客，先不要假設房屋過戶後就能立刻入住。依民法第 425 條，在房屋出租並交付、承租人占有中，所有權移轉後，租約原則上仍對受讓人繼續存在；法律另列未經公證且超過五年或未定期限的不動產租約等例外。個案是否符合要件，不能只憑賣方口頭說法判斷。〔1〕

買賣不破租賃是什麼？先確認租約與占有

「買賣不破租賃」不是一句可以套用所有案件的口號。民法第 425 條的基本規則是：出租人把租賃物交付承租人、承租人占有中，即使所有權讓與第三人，租賃契約對受讓人仍繼續存在。條文同時排除未經公證、期限超過五年或未定期限的不動產租約；因此應先取得完整租約並確認實際占有，再請地政士或律師按個案判讀。〔1〕

先分清交易時房屋的實際狀態
狀態買方應確認不要只靠
租期內、承租人占有租約期限、租金、押金、提前終止、修繕爭議及是否承接。「過戶就能請他搬走」的口頭保證。
租約將到期是否已依法通知、承租人是否書面確認搬遷日，以及賣方未完成時的契約效果。只有房仲轉述的預計搬家日。
賣方稱已終止終止依據、通知與送達證明、押金結算、鑰匙返還及現況空屋。沒有文件或仍由承租人使用的「已處理」。

如果租約是不定期限，出租人也不能只因出售或新屋主想自住就當然要求立即遷出。土地法第 100 條列出出租人收回房屋的法定情形；爭議案件應由專業人士依租約、通知與實際事實判斷。〔2〕

出價前要拿哪些文件？不要只看一頁租約

  1. 完整租約與附件：含簽名頁、續約或變更文件、家具設備清單、點交紀錄；核對出租人、承租人、房屋範圍與簽約日期。
  2. 期限與租金：起訖日、月租、繳款日、已預付期間、是否欠租，以及租金是否含管理費、水電或其他費用。
  3. 押金資料：約定金額、實收證明、是否曾扣抵及目前應交接餘額。租賃住宅條例規定押金不得超過兩個月租金總額，租約消滅且租賃債務抵充後，剩餘押金應返還。〔3〕
  4. 占有人與使用範圍：現場有哪些人、是否有轉租或同住人、車位與附屬空間是否一併出租；不要以戶籍資料取代現場及書面確認。
  5. 通知與往來：續租、調租、修繕、提前終止、欠費或搬遷協議的訊息、存證信函及送達資料。
  6. 爭議與修繕：漏水、設備、費用、損害或押金扣抵是否尚未處理，避免過戶後才發現責任邊界不清。

核對方式：租約文字、賣方陳述、承租人確認與現場使用狀態應能互相對上。若承租人不同意賣方說法、文件不全或不允許確認占有狀態，先把它當成未解決風險，而不是推定沒有問題。

自住買方怎麼選？空屋交付與承接租約分開寫

需要固定日期入住：要求賣方完成空屋交付

如果你必須在特定日期自住，交易條件應以「賣方於約定日完成合法終止租約、承租人遷出、返還鑰匙並空屋交付」為核心。不要自行向承租人承諾搬遷費，也不要把賣方與承租人的協議責任轉成過戶後由你處理。可約定在空屋驗收完成前保留一部分價款，並寫清未完成時的延期、解除、違約或價款處理方式；具體條款請交由地政士或律師依交易設計。

可以等租期屆滿：書面承接租約

若接受租約繼續，契約應列出租約版本、承租人、租期、租金、押金、預收租金、欠費、修繕事項，以及從哪一天起由買方承接出租人權利義務。通知承租人所有權移轉、收款帳戶與聯絡方式時，應留下送達或收訖紀錄，避免承租人收到不同付款指示。

青安貸款與自用住宅稅務各有資格及實際居住、使用等條件；有租約或未能入住可能影響個案文件與時程。出價前應把預計交屋、遷入、設籍與申貸日期交給承貸銀行及稅捐機關確認，不要把「自住購屋目的」直接等同「已符合所有方案條件」。

押金、租金與費用怎麼交接？用結算表鎖定截止日

押金不是賣方出售後就能忽略的款項。若買方承接租約，交易文件要列出賣方實際收取及應移交的押金餘額，並讓承租人知道新出租人承接的數字。若租約在交屋前終止，則應由賣方先完成租金、費用、損害與押金結算，交付證明。

  • 租金：以所有權移轉日、點交日或契約另定基準日分算，處理已預收及未收款項。
  • 押金：記載原收金額、已抵充項目、交接餘額、保管與日後返還責任。
  • 管理費與水電瓦斯：抄表並取得截止日帳單或結清資料；分清承租人、賣方與買方各自負擔期間。
  • 家具設備：用照片與清單確認屋主所有、承租人所有及租約附帶設備，避免空屋點交時誤搬或遺留。

最好由賣方、買方與承租人共同確認一份交接紀錄；若無法三方簽署，至少要有買賣契約附件、賣方交付憑證及通知承租人的可驗證紀錄。

買賣契約要寫哪些條件？至少留下這 8 項

  1. 成交標的是以現有租約承接，還是必須空屋交付。
  2. 租約、附件、收款與通知文件的清單及交付期限。
  3. 承租人姓名、占有範圍、租期、租金、押金與已預收費用。
  4. 租金、押金、管理費與水電等各項費用的結算基準日。
  5. 賣方應處理的欠租、修繕、損害及其他爭議。
  6. 承租人遷出、清空、返還鑰匙及買方複驗的完成日。
  7. 文件或空屋交付未完成時，價款保留、延期、解除或違約處理。
  8. 交屋後由誰、在何時、用何種方式通知承租人新的權利人與付款資訊。

不要在要約或斡旋書只寫「租客會搬」。若這是購買前提，就把可驗收的結果、完成日期與未完成效果放進出價條件，再帶入正式契約。出價文件的基本寫法可搭配中古屋斡旋金與要約書清單。

交屋當天怎麼點交？分成有人承租與空屋兩套

承接租約

  • 核對房屋現況、承租範圍、家具設備、鑰匙及車位。
  • 簽收租約正本、押金與預收租金明細、繳租紀錄和修繕往來。
  • 三方確認租金截止日、下一期收款人、帳戶及聯絡方式。
  • 以可留存方式通知承租人所有權移轉及後續窗口。

空屋交付

  • 確認人員與私人物品已遷出，所有鑰匙、門禁卡及遙控器已交回。
  • 拍照記錄屋況、設備及水電瓦斯表底，對照租約點交與買賣契約。
  • 取得押金、租金、費用與承租人返還房屋的結算資料。
  • 完成買方複驗後，再依契約決定保留款或尾款的支付。

一般設備、費用、戶籍及文件點交，可接著使用中古屋交屋點交清單；產權與使用資料則可回到中古屋產權與屋齡查核指南。

一頁式查核清單：看屋到交屋逐項勾選

  • □ 現場確認承租人、占有範圍與實際使用狀態。
  • □ 取得完整租約、續約、變更、設備及點交附件。
  • □ 核對租期、租金、押金、預付費用、欠費與修繕爭議。
  • □ 決定承接租約或由賣方空屋交付，沒有模糊中間狀態。
  • □ 自住時程已把合法終止、遷出、複驗及貸款稅務確認留出時間。
  • □ 出價與正式契約都寫明結果、期限、文件及未完成的效果。
  • □ 結算表列出押金、租金、管理費、水電瓦斯與設備歸屬。
  • □ 交屋後通知、付款資訊與聯絡窗口有送達或收訖紀錄。
