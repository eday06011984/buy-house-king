房貸共同借款人、保證人差在哪？責任與簽約清單

買房資訊王｜發布與資料查核：2026-11-28

先講答案：共同持有房屋、共同出錢與共同負擔銀行債務不是同一件事。借款人或依法、依契約成立的連帶債務人，可能對銀行負擔全部債務；一般保證人是在主債務人不履行時依保證契約負責；擔保物提供人則是以自己的不動產設定抵押權。不要只聽「一起貸」或「幫忙擔保」，要逐份看貸款、保證及抵押權文件。
銀行實際採用的角色、授信條件與契約文字可能不同。本文整理法規與簽約查核點，不代表銀行一定核准某種組合，也不代替個案法律或授信意見。

金管會的個人購屋貸款定型化契約說明明確區分：貸款契約是借款人與金融機構的債權關係；抵押權設定契約則是擔保物提供人與金融機構的物權關係。〔3〕 所以房屋所有權人不一定就是唯一借款人，借款人也不當然等於全部房屋的所有權人。

自用住宅房貸，銀行可以要求保證人嗎？

不是看到「房貸」就一律需要保證人。銀行法第12條之1規定，銀行辦理自用住宅放款及消費性放款，不得要求借款人提供連帶保證人；已取得足額擔保時，也不得要求提供一般保證人。若有徵取保證人的合法情形，保證金額應有上限，求償原則也先向借款人進行。〔1〕

現行「個人購屋貸款定型化契約不得記載事項」進一步禁止以共同借款人、連帶債務人或最高限額保證等方式，變相規避上述保護；但借款人為強化自身授信條件，主動提出一般保證人的情形，規範另有說明。〔2〕

先確認是否屬銀行法的自用住宅放款。出租、投資、週轉或其他用途的案件，不能直接套用全部自用住宅保護。若銀行要求新增關係人，應請承辦人書面說明角色、原因與責任，不要只接受口頭稱呼。

共同借款人就是一人負責一半嗎？

不一定。共同借款只是日常用語，真正責任由契約及法律關係決定。民法第272條規定，數人明示對債權人各負全部給付責任時，成立連帶債務；債權人得對其中一人或數人請求全部或一部給付。連帶債務人彼此私下約定各付一半，主要是內部分擔安排，通常不會自行縮小銀行依契約可請求的範圍。〔4〕

  • 確認自己簽的是借款人、共同借款人、連帶債務人，還是僅提供房屋抵押。
  • 確認本金之外，是否包含利息、遲延利息、違約金、費用及其他約定債務。
  • 確認扣款帳戶只是一種付款方式，不代表只有帳戶持有人對銀行負責。
  • 共同買方的內部分擔協議，應與房屋持分、實際付款及銀行契約一起核對。

一般保證人有哪些責任與權利？

民法第739條將保證定義為：債務人不履行時，由保證人代負履行責任。除契約另有約定外，保證債務可包含主債務的利息、違約金、損害賠償及其他從屬負擔。一般保證人原則上有先訴抗辯權，可在債權人尚未就主債務人財產強制執行而無效果前拒絕清償，但民法也列有不得主張的例外。〔4〕

銀行法第12條之2另規定，自用住宅放款及消費性放款的保證契約，自成立日起有效期間原則不得逾15年；但保證人書面同意者不在此限。這不代表所有保證責任都自動在15年消滅，仍要核對案件性質、契約日期、書面同意及其他約定。〔1〕

保證人簽名前：
  • 取得完整貸款與保證契約，不只看簽名頁。
  • 圈出最高保證金額、期間、主債務範圍及催收通知地址。
  • 確認是否另簽本票、最高限額保證或預先放棄權利的文字。
  • 評估最壞情境下，是否能承擔本金、利息與費用。

擔保物提供人不是只到場簽名

民法第860條規定，普通抵押權可由債務人或第三人，以不移轉占有的不動產擔保債權；債權人得就實行抵押權後的價金優先受償。換言之，第三人即使不是借款人，只要用自己的房屋設定抵押權，違約時該房屋仍可能面臨實行抵押權。〔4〕

金管會的個人購屋貸款定型化契約應記載事項要求，借款人或第三人提供擔保物時，抵押權擔保範圍原則限於本貸款契約的債務；若要連結未來其他債務，須由擔保物提供人另以書面同意。〔3〕 對保時應逐字核對「本筆貸款」與「最高限額抵押權」文件，不要只問設定金額。

共同買房時，房屋持分與銀行債務要怎麼對齊？

產權登記、銀行債務與雙方出資約定是三條不同的線。兩人各持有50%，不代表銀行債務自然各負50%；只有一人登記房屋，也不表示另一位共同借款人沒有銀行債務。簽約前把以下四張表放在一起：

  1. 產權表：土地、建物、車位登記人及持分。
  2. 出資表：自備款、稅費、裝修及房貸本金由誰支付。
  3. 銀行角色表：借款人、共同借款人、保證人、擔保物提供人。
  4. 退出表：出售、買回、分手、離婚、死亡或無法付款時的順序。

若是夫妻、情侶或家人共同買房，可搭配共同買房持分、出資與退出清單，避免只在產權或只在貸款其中一邊留下約定。

共同借款人或保證人想退出，可以私下改約嗎？

不能只靠兩人私下簽字就解除銀行契約。即使房屋持分已移轉、雙方已分手或其中一人承諾獨自還款，原共同借款人、連帶債務人、保證人或擔保物提供人的責任是否解除，仍要依銀行同意、重新審核、清償、換約及抵押權變更結果判斷。

  1. 先向銀行索取目前全部契約與設定資料，確認每人的正式身分。
  2. 詢問退出需要清償、轉貸、變更債務人、補充財力或重新設定哪些文件。
  3. 再計算持分移轉的買賣或贈與、稅費及地政登記，不先假設銀行一定同意。
  4. 以銀行書面核准及完成文件為準；不要把內部協議當成已解除對銀行責任。

房貸對保前，逐項確認

  • □ 每位簽署人的角色已寫出，不只記「一起貸」或「幫忙簽」。
  • □ 確認案件是否屬自用住宅放款，以及要求新增關係人的書面理由。
  • □ 借款與連帶債務範圍、金額、期間、利息、費用及違約條件已看懂。
  • □ 保證契約的金額、期間、先訴抗辯及通知方式已核對。
  • □ 抵押權擔保本筆或其他債務、最高限額與書面同意範圍已核對。
  • □ 產權持分、實際出資與銀行角色沒有互相矛盾。
  • □ 一方未付款、出售、移轉持分或退出時的內部處理已書面化。
  • □ 已取得完整契約副本並保留銀行書面說明，不只保存試算或對話。

若仍在買房前評估階段，先看房貸預審與正式核貸差別；核准後再用房貸對保、設定與撥款清單確認時間與文件。
