中古屋凶宅怎麼查？非自然死亡揭露與簽約清單

買房資訊王｜發布與官方資料查核：2026-11-07

先說結論：沒有一個公開查詢結果能替代完整揭露。現行建物現況確認書第7項，問的是建物專有部分是否曾發生兇殺、自殺、一氧化碳中毒或其他非自然死亡，並分成賣方持有期間與持有前的認知。持有前可勾「確認無」「知道曾發生」或「不知道曾否發生」；其中「不知道」不等於已確認沒有。〔1〕
「凶宅」是常見用語，個案是否構成交易上的重大瑕疵、應否解除或減價，仍會受事實、契約內容、揭露與證據影響。本文提供的是購屋查核方法，不替特定物件下法律結論。

建物現況確認書第7項，分兩個時間層次

先照官方欄位讀，不要把未知改讀成沒有
時間現行選項買方解讀
賣方產權持有期間是／否；若是，填發生時間。請賣方勾選並簽章；「否」是賣方對自己持有期間的陳述，不是第三方調查證明。
賣方持有前確認無／知道曾發生／不知道曾否發生；知道時填時間。「不知道」表示資訊仍未確定。買方要自行決定補查、議價、設成交條件或不交易。

表單列舉兇殺、自殺、一氧化碳中毒或其他非自然死亡，範圍寫的是建物專有部分。官方現行附件還要求買賣雙方簽章，並提醒確認內容應與交屋時現況相符。〔1〕

經紀業受託銷售時，另有不動產說明書。現行規範要求說明賣方產權持有期間是否發生非自然死亡；兩份文件用途不同，不能只拿口頭答覆或一張未填完整的現況確認書代替。〔2〕

同棟其他樓層、公共區域或持有更早以前，也一定揭露嗎？

不能把官方表單對「專有部分」的問題，自動擴張為所有公共區域、同棟其他戶或鄰近位置；也不能反過來說表單未問就永遠不重要。若你在意的範圍比官方欄位更廣，應在簽約前用書面明確提出，例如：

  • 本戶專有部分與附屬建物；
  • 約定專用範圍、露臺、停車位；
  • 梯間、屋頂、地下室等特定公共區域；
  • 同棟建物其他樓層或特定範圍；
  • 希望查核的時間範圍與賣方「已知」的基準。

內政部住宅消費爭議案例曾記載，買方因得知同棟不同樓層曾發生非自然死亡而申訴，最後由雙方調解解除契約；這是個案處理結果，不代表所有同棟事件都會自動產生相同法律效果。〔4〕

簽約前怎麼查？用「文件、書面提問、關係人」三層交叉核對

  1. 先收文件：取得填寫完整並簽章的建物現況確認書；有仲介時，同時取得不動產說明書與完整買賣契約附件。
  2. 逐字書面問：不要只問「是不是凶宅」。照你在意的空間、事件類型與時間範圍，請賣方及經紀人分別答覆，並註明是確認無、已知曾發生或不知道。
  3. 釐清賣方持有期間：持有時間很短時，更要問取得原因、前手提供的現況文件及賣方對持有前事件的資訊來源。
  4. 詢問社區可驗證資訊：在不侵害個資、不散布未證實訊息的前提下，可請管委會或管理人員說明是否有可供查閱的公告、會議紀錄或修繕紀錄；沒有紀錄不等於事件未發生。
  5. 核對說法是否一致：廣告、帶看人員、賣方、現況確認書、不動產說明書與契約若答案不同，先暫停付款或簽署，要求書面釐清。

網路貼文、鄰居轉述與地址搜尋可以提供查核線索，但可能同名、錯址、已刪除或內容不完整，不能當作唯一結論。政府公開資料查無結果，也不能直接證明「從未發生」。

把在意範圍寫進契約，至少回答5件事

  1. 標的範圍：只限專有部分，還是包含附屬建物、約定專用、公共區域或同棟特定範圍？
  2. 事件與期間：哪些事件需要陳述，從何時起算？不要只留一句「非凶宅」。
  3. 資訊標準：要求賣方就已知事實陳述，還是須提供特定文件或查證結果？
  4. 補件期限：未填、未知或說法矛盾時，何時以前補充？款項是否在補件前保留？
  5. 不符時處理：若陳述不實或查核結果不符交易前提，雙方如何通知、協商、解除、返還款項或處理違約責任？

可交給專業人士調整的句型：「賣方就＿＿範圍於＿＿期間內，依其所知陳述＿＿；應於＿＿日前提供＿＿。如書面陳述與可證明事實不符，雙方依＿＿處理。」條款的法律效果與證明責任應由地政士或律師按個案確認。

看到這6種情形，先停下來補問

  • 第7項空白、整頁劃線或沒有雙方簽章。
  • 持有前勾「不知道」，卻口頭保證「一定沒有」。
  • 廣告或仲介說法和賣方勾選不同。
  • 賣方持有時間很短，且無前手現況文件或說不清資訊來源。
  • 只回答本戶，卻把你明確在意的公共區域或同棟範圍避而不答。
  • 要求先付定金或簽約，再補現況確認書與不動產說明書。

以上只是提高查核優先度，不等於物件已發生事件。重點是讓未知保持「未知」，不要被含糊話術改寫成已確認安全。

簽約後才發現資訊不一致，先做哪4件事？

  1. 保存原始資料：廣告、對話、現況確認書、不動產說明書、契約、付款證明及新發現的可核實資料。
  2. 書面通知：列出哪一項陳述與何種證據不一致，要求賣方與經紀業在期限內回覆。
  3. 不要自行擴大損失：在未確認契約效果前，不要只憑網路訊息單方面停款、進屋或處分標的。
  4. 依個案求助：可向所在地消費服務中心或地政主管機關反映，涉及解除、減價、損害賠償或時效時，儘快讓律師審閱完整資料。

是否能解除契約或請求其他救濟，不只取決於事件本身，還要看賣方或經紀業陳述、買方交易前提、契約條款、證據與時間點，不能用單一案例推定結果。
