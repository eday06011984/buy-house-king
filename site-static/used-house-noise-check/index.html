先說結論：一次安靜的看屋不能證明長期安靜。至少安排平日通勤時段、平日晚間與假日其中兩次複看，分開記錄道路與營業場所、鄰居活動，以及電梯、抽水馬達、冷卻水塔等社區設備。室內要同時測試開窗與關窗，並把「聲音來源、發生時段、房間位置、持續或間歇、是否伴隨振動」逐項留下來。

《噪音管制法》把工廠、娛樂或營業場所、營建工程及擴音設施等持續性、可量測來源納入管制；不具持續性或不易量測、足以妨害生活安寧的聲音，則由警察機關依相關法規處理。〔1〕 所以買方不只要問「吵不吵」，還要問清楚來源與規律。

看屋噪音要選哪些時段？至少做兩次有目的的複看

  1. 平日早晚尖峰：觀察通勤車流、垃圾車、校園接送、店家開關門與社區電梯密度。
  2. 平日晚間：確認鄰居返家後的腳步、家具、電視、樂器及樓板衝擊音，也聽空調與抽水設備。
  3. 假日白天或晚間：補看平日不明顯的住戶活動、附近商圈、活動場地、廟會或裝修。
  4. 設備預定運轉時：請管理人員說明抽水、污水、冷卻、垃圾壓縮或發電機測試時間，能合法安全操作時再現場確認。

官方噪音標準本身就區分日間、晚間與夜間，而且各類噪音管制區的時段及上限不同。這不表示買方要自行做執法量測，而是提醒你：白天下午一次看屋，無法代表晚間或夜間的居住感受。〔3〕

屋外環境怎麼查？從棟別、樓層與開窗方向開始

  • 在社區入口、棟別外牆、停車出入口與房屋窗邊各停留數分鐘，記錄哪一側最明顯。
  • 查看主要臥室與客廳面向，是否正對高架道路、彎道、路口、坡道、裝卸區、球場、校園廣播或營業場所後場。
  • 同一棟不同樓層不一定越高越安靜；高架、軌道、聲音反射與遮蔽物會改變感受，應以目標戶別現場確認。
  • 向地方環保局公告確認地址所在噪音管制區類別，但不要把區類當成該戶實測保證。各縣市依法依土地使用與現況劃定，且會定期檢討。〔4〕
  • 如果附近有工地、空地或尚未營運店面，查詢建照、使用分區與招牌資訊，並把未來可能的營運或施工時段列為風險。

電梯、抽水馬達與低頻振動怎麼查？

持續的嗡聲、低頻聲或震動常比偶發車聲更難用短時間看屋捕捉。環境部說明，工廠、娛樂或營業場所等來源已有低頻噪音管制；住宅設備是否適用，仍要看來源、地方公告及個案。〔5〕

  1. 畫相對位置：請管理人員標示電梯機房、升降道、抽水與污水機房、水箱、風機、冷卻水塔、發電機及變壓器。
  2. 逐房停留：臥室床頭牆、天花板角落、浴室管道間、廚房與陽台各靜聽，手掌輕觸牆面或固定櫃體感受是否同步振動。
  3. 要求運轉紀錄：詢問設備何時啟停、近年維修、住戶陳情、隔音或減振改善，以及改善後是否仍有人反映。
  4. 不要只聽空屋：冷氣、冰箱與循環設備關閉時較易分辨建物聲源；之後再開啟預計留下的設備，避免把家電聲與社區設備混在一起。

室內如何做可比較的噪音紀錄？

每次複看都用相同順序，才能比較。先關閉室內可控制設備，門窗全關記錄一次；再依序打開主要窗戶與陽台門記錄一次。客廳、主臥、次臥及工作空間都要停留，不要只站在仲介說話的位置。

紀錄格式：「日期時間＋天候＋房間／位置＋門窗狀態＋來源方向＋持續／間歇＋是否振動＋當時附近活動＋照片或錄音編號」。手機數字若有記錄，請註明手機與 App，只作同設備相對比較。

若某聲音會影響睡眠、工作或幼兒作息，重點不是它能否被普通錄音完整收錄，而是能否在預期使用時段重複出現。需要正式判定時，應由主管機關或合格專業人員依適用方法量測。

簽約前可向賣方與管委會問哪些資料？

  • 近年住戶大會或管委會紀錄中，有無噪音、振動、設備機房、電梯、抽水馬達、冷卻水塔或隔音改善議題。
  • 設備保養、故障、隔音與減振施工紀錄，以及目前運轉排程。
  • 標的戶或相鄰戶是否曾提出書面反映、調解、環保陳情或警方處理；請賣方就其所知書面回答。
  • 住戶規約對裝修時段、樂器、寵物、地板材料、公共區域及營業使用的限制。
  • 附近店家、工地或公共設施的實際營業、施工及活動時段。

尚未成為區分所有權人時，可請賣方調閱可提供的規約、會議與維修資料，並把未提供項目列入出價或簽約前補件條件。社區文件的完整查核可搭配中古屋管委會與公共基金清單。

噪音標準與陳情管道，買方怎麼正確理解？

噪音管制區分四類，第二類以住宅使用為主且需要安寧；第三類則以住宅為主但混合商業或工業使用。地方政府依法公告實際區界，不能只憑門牌所在的都市計畫名稱推定。〔4〕

不同來源的權責也不同：環境部資料將工廠、營業場所、營建工程、擴音設施等列為環保機關處理範圍；不具持續性或不易量測的近鄰聲音，通常依警察或公寓大廈相關管道分流。〔5〕〔6〕 買房前查到曾有陳情，不等於已經改善；查不到公開紀錄，也不能證明從未發生。

發現噪音疑慮，如何寫進出價與契約？

  1. 補查條件：列明要取得的規約、會議、維修或陳情相關資料，以及提供期限。
  2. 再次進場：約定特定時段複看或設備運轉測試，寫明可進入的位置與陪同人員。
  3. 賣方說明：不要只寫「環境安靜」；改為請賣方就已知來源、時段、處理與改善情形逐項書面回答。
  4. 結果處理：若補件、複看或專業檢查不符買方需求，如何調整價款、改善或不再進行，應由地政士或律師依個案擬定。
  5. 附件留存：把複看表、相對位置圖、錄音照片編號、書面答覆與改善文件列為附件。

看屋噪音12項複看清單

  1. 安排至少兩個不同日期或時段，不只跟著第一次看屋時間。
  2. 在社區外、入口、棟別下方、停車出入口與目標戶分別停留。
  3. 確認主要窗戶與臥室面向的道路、軌道、學校、商圈與工地。
  4. 開窗與關窗各記錄一次，確認聲音方向及門窗隔音差異。
  5. 客廳、每間臥室、浴室管道間、廚房及陽台逐處靜聽。
  6. 試乘電梯並在電梯升降時留在相鄰房間觀察。
  7. 確認抽水、污水、風機、冷卻、發電及變壓設備的位置與時程。
  8. 記錄嗡聲、低頻、震動、拖椅、腳步、關門與突發尖峰聲。
  9. 向賣方、管理人員與不同住戶交叉詢問，不只採信單一口頭回答。
  10. 索取規約、會議紀錄、設備維修與隔音減振資料。
  11. 手機數字只作相對比較；重大疑慮安排適當的專業檢測。
  12. 把補件、複看、改善與未完成事項寫進交易文件。
