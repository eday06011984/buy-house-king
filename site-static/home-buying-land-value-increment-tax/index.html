買房土地增值稅誰繳？賣方申報、買方代繳與過戶清單

買房資訊王｜發布與資料查核：2026-11-05

一般房地買賣的土地增值稅，法定納稅義務人是原所有權人，也就是賣方。但這筆稅不是買方可以完全不管的「賣方費用」：雙方要在訂約後30日內申報土地移轉現值，完成繳稅或取得免稅、不課徵證明後，才能接續辦理所有權移轉登記。賣方逾期不繳時，買方可能面臨過戶停住，並可依法向稽徵機關申請代繳。

土地增值稅與房地合一所得稅不同。土地增值稅在土地移轉時，以土地公告現值相關基礎計算；房地合一稅是交易所得稅，另有取得成本、費用、持有期間與申報期限。不要把兩者合併成同一筆。

土地增值稅是買方還是賣方繳？

依土地移轉原因判斷法定納稅人
移轉方式法定納稅義務人常見情境
有償移轉原所有權人買賣、交換等；一般房屋買賣即由賣方負擔。
無償移轉取得所有權人贈與或遺贈，通常由取得土地的一方負擔。
設定典權出典人不是一般買賣，但同屬土地稅法列明情形。

土地稅法第5條與財政部說明都明列，一般買賣屬有償移轉，土地增值稅納稅義務人是原所有權人。〔1〕〔2〕

買賣契約可以另約定由誰實際負擔費用，但私人約定不會改變稅法上的納稅義務人。若買方同意代付，應把金額、付款方式、能否從尾款扣抵、繳款證明與退稅歸屬寫清楚，不要只寫「稅費各自負擔」。

土地增值稅是用成交總價計算嗎？

不是。土地增值稅以土地移轉時的申報移轉現值，減除按物價指數調整後的前次移轉現值或原規定地價，再扣除符合規定的土地改良費用，計算土地漲價總數額。它不是把整筆房地成交價直接乘上一個稅率。〔2〕

稅率只是公式的一部分，實際稅額以地方稅機關核定為準
類型稅率重要提醒
一般用地依漲價倍數分級20%、30%、40%採累進計算；長期持有符合規定時，超過最低稅率部分可減徵。
自用住宅用地10%須由出售土地的所有權人符合戶籍、用途、面積及次數等條件並申請。

因此，買方只看到成交價，無法自行精確推算賣方的土地增值稅。應以地方稅稽徵機關核發的繳款書、免稅或不課徵證明為準。

買方要自住，賣方就一定適用10%嗎？

不一定。自用住宅用地10%優惠看的是賣方在出售前是否符合條件，不是買方買下後打算自住。財政部列出的「一生一次」條件包括地上房屋為土地所有權人或其配偶、直系親屬所有並設籍，出售前一年未出租或營業，以及都市土地不超過3公畝、非都市土地不超過7公畝等。〔3〕

曾使用「一生一次」後，若要再用「一生一屋」，還要符合出售時家戶無其他房屋、持有及設籍連續滿6年、出售前5年未出租或營業，以及較小的面積限制。是否核准由地方稅稽徵機關依申報資料認定。

買方完成過戶後，要申請的是持有期間的自用住宅用地地價稅2‰，與賣方出售時的土地增值稅10%是兩套不同制度。可接著閱讀自住房屋稅與地價稅申請指南。

土地增值稅申報、繳稅與過戶怎麼銜接？

  1. 簽訂買賣契約：確認土地標示、持分、申報移轉現值、申報責任與付款節點。
  2. 30日內共同申報：土地稅法第49條規定，權利人與義務人原則上應於訂約日起30日內，共同向土地所在地稽徵機關申報土地移轉現值。逾期申報可能改用收件日當期公告土地現值核定。〔1〕
  3. 等待核定並繳納：一般案件原則上由稽徵機關在收件後7日內核定；自用住宅用地案件可延長為20日。納稅義務人收到繳款書後應於30日內繳納。
  4. 完成查欠：欠繳地價稅等土地稅未清前，不能辦理移轉登記。〔4〕
  5. 申請所有權移轉登記：地政機關會要求土地增值稅繳納、免稅或不課徵證明，以及契稅相關證明等文件。

買方的安全做法，是把「取得土地增值稅完成證明」設為尾款或過戶撥款的文件條件之一，再依履約專戶或代辦流程付款，不要只憑賣方口頭表示已處理。

賣方逾期不繳，買方可以代繳土地增值稅嗎？

可以申請，但不要自行匯款後才補文件。土地稅法第5條之1規定，納稅義務人未在期限內繳納時，取得所有權人得代為繳納；法律上的納稅義務人仍是賣方。〔1〕

實務上應先向原受理申報的地方稅稽徵機關確認代繳程序與繳款書，再依買賣契約處理尾款扣抵、履約專戶撥款及收據保存。若買方代繳後產生退稅，退還對象會涉及稅單納稅義務人與代繳證明，不宜只靠雙方口頭約定。〔5〕

代繳是避免過戶卡關的法定機制，不等於買方當然要額外承擔賣方稅負。是否從價金扣回、誰負擔衍生費用及期限延誤責任，仍應依契約與個案證據處理。

同時賣舊屋、買新屋，可以申請土地增值稅重購退稅嗎？

如果你不只是買方，同時也出售原自用住宅，可檢查重購退稅。財政部列出的主要條件包括：先賣後買或先買後賣須在2年內、出售與重購土地所有權人為同一人、兩地房屋及戶籍符合自用條件、出售前一年未出租或營業，且重購土地地價須高於原出售土地地價扣除土地增值稅後的餘額。〔6〕

退稅金額不是直接退回全部稅款，需依重購與出售土地的申報移轉現值差額計算；受理單位是原出售土地所在地的地方稅稽徵機關。換屋時間、登記名義及戶籍規劃會影響資格，簽約前宜先取得書面試算。

買方簽約與付款前，照著查這8項

  1. 契約是否寫明土地增值稅由賣方申報及負擔？
  2. 訂約日起30日申報期限由誰追蹤？逾期責任如何處理？
  3. 賣方是否申請自用住宅10%稅率？等待核定的時間是否排進過戶日程？
  4. 尾款或履約專戶撥款前，是否要取得繳納、免稅或不課徵證明？
  5. 土地、房屋是否另有欠繳地價稅或房屋稅，可能阻擋移轉？
  6. 若賣方逾期未繳，買方代繳的申請、尾款扣抵與證明如何辦理？
  7. 契約若約定買方實際負擔，是否列出核定稅額上限、付款方式與退稅歸屬？
  8. 完成過戶後，買方是否另行申請自住房屋稅與自用住宅地價稅？

買方自己的契稅、印花稅與所有權移轉登記費，請用買房稅費試算與交屋清單分項估算；若同時出售舊屋，另看房地合一稅自住優惠，避免把不同稅目混在一起。
