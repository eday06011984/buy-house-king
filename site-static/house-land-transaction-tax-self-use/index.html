房地合一稅自住優惠怎麼算？400萬免稅、10%稅率與6年條件

買房資訊王｜發布：2026-10-30｜最後修改：2026-10-30｜官方資料查核：2026-10-30

先講答案：個人出售符合房地合一稅範圍的自住房地，若本人、配偶或未成年子女在該屋辦竣戶籍登記、持有並實際居住連續滿6年，交易前6年沒有出租、營業或執行業務使用，而且家戶交易前6年未曾使用這項優惠，課稅所得400萬元以內免稅；超過400萬元的部分按10%課稅。
「400萬元」是課稅所得免稅額，不是成交價減400萬元，也不是每位家人各有400萬元。即使計算後免稅、虧損或沒有應納稅額，適用房地合一稅的交易原則上仍須在完成所有權移轉登記日的次日起30日內申報。

房地合一稅自住優惠，要同時符合哪3項條件？

依所得稅法第4條之5與財政部稅務入口網說明，三項條件缺一不可：

  1. 連續滿6年：個人或其配偶、未成年子女在該房屋辦竣戶籍登記，持有並實際居住連續滿6年。
  2. 6年內無出租或營業：交易前6年內，房屋不能出租、供營業或執行業務使用。
  3. 家戶6年內未用過：個人、配偶及未成年子女在交易前6年內未曾適用這項自住房地租稅優惠。

「持有6年」不等於一定符合：戶籍登記、實際居住與使用狀態也要連續符合。只把戶籍遷入但沒有實際居住，或期間曾出租、作為營業場所，都可能影響適用資格；個案事實與證明仍由國稅局審核。

這和房屋稅1%／1.2%、地價稅2‰是同一優惠嗎？

不是。同一間自住房屋可能涉及三套不同稅目、不同期間與不同主管機關，不能用其中一項核准推定另外兩項也符合。

400萬元免稅額與10%稅率，怎麼計算？

房地合一稅不是直接用成交價乘稅率。財政部列示的基本架構是：

課稅所得＝成交價額－取得成本－相關費用－土地漲價總數額
符合自住優惠的應納稅額＝（課稅所得－400萬元免稅額）×10%；若課稅所得不超過400萬元，這項交易的自住房地所得免稅。

純算式示例

假設成交價1,500萬元、可證明的取得成本1,000萬元、相關費用30萬元，並減除土地漲價總數額50萬元，課稅所得為420萬元。若三項自住條件都符合，免稅額400萬元，超過的20萬元按10%計算，應納稅額為2萬元。

這只是說明公式的假設案例，不代表個案可直接採用。成本、費用、土地漲價總數額、持分與新舊制比例都可能改變結果；部分房地分次取得、繼承或受贈者，應另外確認取得日與計算方式。

從買房第一天起，哪些成本憑證要留？

可減除金額需要契約、收據、發票、匯款或其他證明。財政部說明，取得房地後達可供使用狀態前的必要費用，例如契稅、印花稅、代書費、規費、仲介費，以及符合規定的增置、改良或修繕支出，可能列入成本或費用；實際仍依支出性質與證明審核。

  • 買入與賣出的買賣契約、價款收付與銀行匯款紀錄。
  • 契稅、印花稅、登記規費、代書費與仲介費憑證。
  • 增加房屋價值或效能、且非短期耗竭的改良修繕契約、發票與付款紀錄。
  • 土地增值稅繳款書或免稅證明，以及核准的土地改良費用資料。
  • 戶籍、實際居住與無出租營業的相關紀錄，供未來查核資格。
常見不能直接減除的持有支出：取得後使用期間的房屋稅、地價稅、管理費、清潔費與房貸利息等，財政部明列不得當作房地交易費用減除。不能把多年持有成本全部塞進房地合一稅公式。

若未提示費用證明，或所提示的費用證明金額未達成交價額3%，稽徵機關得按成交價額3%計算可減除費用，但上限30萬元；這不是每案自動固定扣30萬元，也不應取代保存真實憑證。

出售後要在何時、向哪裡申報？

  1. 確認交易日：一般房屋、土地以完成所有權移轉登記日為交易日。
  2. 起算30日：自完成所有權移轉登記日的次日起算30日內辦理，不是等到隔年5月綜合所得稅申報。
  3. 準備文件：房地合一稅申報書、買入與賣出契約、價款收付、成本與必要費用證明，以及自住資格資料。
  4. 先繳後報：有應納稅額時，先繳納並附繳款收據，再向管轄國稅局申報；也可使用財政部提供的線上申報服務。
  5. 保留核定：留存申報收件、繳款與國稅局核定資料，避免日後重購或再次出售時無法核對。

未按期申報可能有行為罰；如另有應補稅額，也可能產生漏稅罰。即使自認符合400萬元免稅、沒有獲利或交易虧損，仍不要自行略過申報。

準備長期自住，買房時先做這8件事

  1. 確認房地所有權人、預計設籍者與實際居住者如何安排。
  2. 所有權移轉後儘速完成符合實際情況的戶籍登記，不用口頭約定替代。
  3. 保存買價、稅費、代書、仲介與登記規費憑證。
  4. 裝修前把工程範圍、報價、發票與付款人寫清楚。
  5. 不把房屋出租、營業或執行業務使用；使用狀態改變時先問國稅局。
  6. 家戶若出售其他自住房地，先查6年內是否已使用過優惠。
  7. 預計出售前，核對持有、戶籍與實際居住是否已連續滿6年。
  8. 把完成移轉登記後30日申報寫進賣屋與代書時程。

常見問題

住滿6年但戶籍晚一年遷入，可以用自住優惠嗎？

不能只看實際入住日。法規同時要求辦竣戶籍登記、持有並居住連續滿6年；若戶籍未滿6年，通常不符合這項6年條件，仍應以個案資料請國稅局確認。

夫妻各賣一間房，可以各扣400萬元嗎？

不是以每位家人各給一次計算。優惠限制涵蓋個人、配偶與未成年子女，家戶在交易前6年內未曾適用才符合；400萬元是符合條件的該筆自住房地課稅所得免稅額。

房屋稅已核准自住，就一定符合房地合一自住優惠嗎？

不一定。房屋稅自住是地方持有稅資格；房地合一稅另要求出售前連續6年的持有、設籍、實際居住、使用與家戶未用過優惠。兩者應分開留證、分開判斷。

400萬元免稅，還需要申報嗎？

需要。符合房地合一課稅範圍的交易，除法定免辦情形外，不論盈虧或有無應納稅額，都應在規定期限內申報。
